# 巨无霸指数 · 中国版

**跑了 38 座城市、170 家麦当劳门店，用官方 MCP 取到真实挂牌价，回答一个问题：中国的巨无霸到底差多少钱？**

答案可能和你想的不一样——**几乎没有差**。

## 三个结论

**① 麦当劳在中国基本是统一定价。**
170 家有巨无霸在售的门店，价格只出现 5 个档位。其中 **86 家（50.6%）都卖 26.5 元**，25.5 / 26 / 26.5 三档覆盖了 **94.7%** 的门店。

**② 唯一的例外是拉萨，而且是整城涨。**
拉萨 5 家门店（八廓商城、柳梧万达、藏游坛城、纳金中路、王府井）**全部 29 元**，比全国中位数高 **9.4%**。这是 38 城里唯一一个"整城偏离"的城市。

**③ 除了拉萨，剩下 37 城就是一个价。**
37 个城市的中位数全部落在 **25.5–26.5 元**之间，最大差距 **1 元**。一线城市并不更贵——**上海 25.5 元，比拉萨便宜 3.5 元**；深圳、广州、北京都在 25.5–26.5 区间。

## 一个被数据否掉的假设

我最初的假设是「景区、车站门店更贵」——毕竟机场和景区溢价是普遍现象。

**实测不支持这个假设。** 名称含「景区」「车站」「码头」「博物院」字样的 5 家门店，均价 26.8 元，普通门店 26.29 元，只差 0.51 元（1.9%）。其中无锡火车站南广场店卖 25.5 元，是全国最便宜的一档。

所以这个项目不是在"发现惊人价差"，而是**用 170 个门店级样本，把一个常见假设证伪**：麦当劳中国的定价是准全国统一的，涨价不跟景区走，只跟城市走——而且只在拉萨走。

## 数据是怎么来的

全部数据通过**麦当劳中国官方 MCP Server** 实时拉取，不是爬虫、不是估算、没有硬编码价格。

```
城市名 + 地标关键词
       │
       ▼
query-nearby-stores  (beType=1, searchType=2, city, keyword)
       │  → data[].storeCode
       ▼
query-meals  (storeCode, orderType=1, beType=1)
       │  → data.meals[code].currentPrice
       ▼
按门店聚合 → 城市中位数 / 极差 / 溢价榜
```

只用了 2 个只读 Tool。**不下单、不支付、不领券、不抽奖**。详见 [MCP_INTEGRATION.md](./MCP_INTEGRATION.md)，含 5 条文档没写的接口踩坑记录。

## 跑起来

```bash
# 1. 拿 Token：https://open.mcd.cn 手机号登录 → 控制台 → 激活
export MCD_MCP_TOKEN=你的token

# 2. 采集（38 城，串行限速 1 秒，约 5 分钟）
python src/collect.py

# 3. 算指数
python src/index.py

# 4. 生成报告 → docs/index.html
python src/render.py
```

无第三方依赖，Python 3.9+ 即可。

## 目录

```
src/mcp_client.py   MCP 调用 + 混合响应 JSON 抽取
src/collect.py      38 城门店与价格采集（断点续采）

```

## 口径与限制

- 价格是**门店到店自提菜单的实时挂牌价**，含会员价/促销时以接口返回值为准；**不含外送价、不含套餐价**。
- 每个城市取按地标搜索到的**前 5 家门店**，不是全量门店。城市代表性与地标选择有关，地标选在市中心商圈。
- **16 家门店菜单中无巨无霸单品**（快捷小站、景区小店等），已如实记为 `null` 并从统计中排除。
- 巨无霸同时存在单品与「巨无霸三件套」（约 54.5 元），本项目只取单品，按名称精确匹配。
- 价格为采集时点（2026-10-22）的快照，活动与调价会使其变动。原始数据见 `data/latest.json`，可复现。
- 复现时的城市数可能因门店变动略有差异。

## 关于巨无霸指数

《经济学人》自 1986 年起用巨无霸价格做购买力平价的民间代理指标，但公开版本只有**国家层面一个数字**。本项目把颗粒度下沉到**城市级、门店级**，用一手门店数据替代二手估算。

## 声明

本项目仅呈现公开挂牌价，不对麦当劳及其商品作任何评价，不与任何其他品牌比较。数据来自麦当劳官方 MCP 的公开查询接口，采用串行限速调用。仓库内不含任何 Token、手机号、订单号或用户标识。

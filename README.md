# 麦门签筒

**摇一支签，今天吃什么都由它定。**

签是随机的，签上那顿饭的价钱是真的。

> 打开就能玩：`web/index.html`（无需 Token、无需安装、手机摇一摇）

---

## 为什么做这个

中午不知道吃什么，是每天都要发生一次的决策瘫痪。菜单越长越选不动——**选项越多，人越不愿意选**。

市面上的解法是"随机推荐"。但纯随机没意思，抽完还是空的。

签筒不一样：**它先给你一个仪式，再给你一个结果，最后告诉你这个结果值多少钱。**

## 三件别处没有的东西

### ⓪ 签筒是一只薯条盒

不是竹筒，是麦当劳自己的红色薯条纸盒——金色双拱、上宽下窄，24 根薯条错落露出盒口。**点一下盒子，或按住鼠标快速左右摇**，盒身会晃、薯条会各自抖动，然后一根薯条抛起来、翻个身、落到盒子旁边，签才展开。

手机端支持真实摇一摇（`devicemotion`），桌面端支持点击与鼠标晃动（速度 + 变向检测），全部用 CSS 与 Web Animations API 实现，无第三方依赖。

### ① 签筒会跟着时辰变

麦当劳 MCP 的 `query-meals` 返回的是**当前时段可售菜单**。上午十点半之前，菜单里根本没有巨无霸——只有麦满分、炒双蛋堡、麦咖啡。

所以这个签筒有 **36 支正签 + 12 支早签**，按你打开时的时间自动切换：

| 时段 | 签筒 | 例子 |
|---|---|---|
| 10:30 前 | 12 支早签 | 「吉士蛋麦满分 + 脆香油条 + 优品豆浆」 |
| 10:30 后 | 36 支正签 | 「巨无霸 + 薯条 + 可乐」 |

不是刻意设计成两套，是**数据本身就是这样**。传统签筒也有子时签、午时签，这里算是碰上了。

### ② 签等不是编的

签分五等：**上上 / 上吉 / 中平 / 中下 / 下下**。

但它不是随手盖的章。每一签在你所在门店都有真实的合计价，签等按**这一签的规格**排（主食 > 小食 > 饮品，同规格比价钱）：

- **上上**：三件齐全、最丰盛的那一支（通常也是总价最高的一支，抽到要认）
- **下下**：只有一杯饮料或一个甜筒，抽到属于考验

换句话说：**签等是算出来的，不是摇出来的。**

### ③ 签外话：把 170 家门店的价格数据接进解签

每一签下面有一栏「签外话」，接的是真实采集的全国价格：

> 巨无霸在杭州卖 **25.5** 元，比拉萨的 **29.0** 元便宜 **3.5** 元。
> 你这一签 3 样东西，合计 **54.5** 元；本店 35 支签的合计价中位数是 **32.0** 元，你比中位贵 **22.5** 元。

这些数字来自**38 座城市、170 家门店**的实测采集。抽签是假的，钱是真的。

## 数据本身也有结论

底层那份全国价格数据自己会说话：麦当劳在中国基本是**准全国统一价**——170 家有巨无霸的门店只出现 5 个价位，**50.6% 都卖 26.5 元**；唯一的整城例外是**拉萨**（5 家店全部 29 元，比全国中位高 9.4%）。完整分析见 [`web/report.html`](web/report.html)。

这就是「签外话」里那句"比拉萨便宜 X 元"的来源。

## 怎么跑

```bash
# 1. 拿 Token：https://open.mcd.cn 手机号登录 → 控制台 → 激活
export MCD_MCP_TOKEN=你的token

# 2. 采集 11 城菜单（早市 + 正餐两套，约 1 分钟）
python src/collect_menus.py

# 3. 打包成网页数据
python src/build_web.py

# 4. 打开 web/index.html，或起静态服务
python -m http.server 8000 -d web
```

只读调用，不下单、不支付、不领券、不抽奖。无第三方依赖，Python 3.9+。

## 签与菜单怎么对上

签诗是固定的（36 + 12 首），但**配餐是从真实菜单里现挑的**：

```json
{ "no": 1, "hex": "乾为天", "mood": "主饱",
  "poem": ["金拱门下立斜阳", "两片纯牛压作梁", "薯条如戟排云上", "一杯冰可落九肠"],
  "main": ["巨无霸"], "side": ["薯条"], "drink": ["可乐"] }
```

运行时拿 `main / side / drink` 的关键词去匹配该门店当前菜单，命中才算这一签可出。所以**每一签抽出来都是能真点到的**，价格也是那一刻的挂牌价。缺货或门店菜单不全的签会自动不进签筒——北京少安格斯、拉萨少冰淇淋，出签数会相应变少（31–36 支之间浮动）。

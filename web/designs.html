Visual direction study · 01—05

薯条盒，不止一种画法。

五款统一使用连贯双拱与简体标题“麦门签：今天吃什么？”。这里只比较造型、线条与质感，不改主页面的菜单、抽签逻辑和交互动画。点击卡片可标记你的选择。

静态设计稿 / 非最终前端 / 可单独选择某一款的局部特征
01 / FLAT VECTOR

经典纯平

完全取消渐变、投影和高光。用两种黄色区分薯条前后层次，红色盒身保留包装弧形，最干净，也最适合做流畅的摇签动画。

零阴影品牌感最直接动画适配最好
02 / PAPER CUT

剪纸拼贴

薯条改成不规则多边形，盒身用错位的纯色纸层表现厚度。仍有“纸”的感觉，但不依赖拟物阴影，比经典纯平更有手作温度。

手作感硬边色块东方趣味
03 / SCREEN PRINT

复古丝网印

深红描边、奶油纸底色、局部网点，像一张老餐馆海报。视觉个性最强，适合把结果签卡也延展成一套复古印刷品。

海报感高辨识度适合社交传播
04 / BOLD ICON

粗线图标

减少薯条数量、放大轮廓，所有元素使用统一粗描边。更像一个现代应用图标，在小屏幕和动画高速运动时仍然清楚。

移动端清晰年轻玩趣图形最简练
05 / ORIENTAL

东方签肆

把薯条轻轻往“竹签”的方向靠，增加签刻短线、朱红描边与小印章。不是古装堆砌，而是用少量东方符号呼应“摇签”的仪式。若希望作品一眼区别于普通麦当劳插画，可以选这款。

中式概念最强签筒语义明确适合延展签卡

选择方式：回复编号即可，例如“01”，也可以组合，例如“01 的干净 + 05 的印章”。选定后再统一修改正式前端，不在本轮反复堆效果。
